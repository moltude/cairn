How to use Cairn

1 · Export from CalTopo as GeoJSON

On your CalTopo map choose Export and pick GeoJSON. It is the only CalTopo format that keeps your folders, icons and colors — GPX and KML both discard them. Drop that file here.

2 · Review the icons

Cairn maps each CalTopo symbol to the closest onX icon. Hover any icon to see why it was chosen. Some waypoints fall back to onX's default pin because CalTopo had no symbol and the name gave no clue — that is often perfectly fine (mile markers, numbered stops). Set an icon only where the meaning matters; choosing an icon — including deliberately choosing “Location” — marks it reviewed.

3 · Edit in bulk

Narrow the list with the search box, the type dropdown, or Needs an icon. Then tick rows — Set icon… and Set color… light up and apply to your selection. Advanced holds Use description as name (when the real information is in the notes) and the export include/exclude controls.

Click a boxSelect one row.
Shift + clickSelect everything between it and the last row you clicked.
Ctrl / ⌘ + ASelect everything currently shown. Press again to deselect.
Header checkboxSelect every row in that folder.
EscClear the selection. While editing a name or description, Esc undoes that edit instead.

Selection always follows what is on screen: filter first, then select all, and you only touch the rows you can see.

4 · Leave things out

Select rows and choose More → Leave out of the onX export. Excluded rows stay visible, struck through, with a restore button. Useful for scratch lines and duplicated tracks. Nothing is ever deleted from your CalTopo file.

5 · Export and import

Cairn writes one set of files per folder and a checklist. This matters: onX creates one folder per import, and names it with a timestamp — never from the filename. So the checklist tells you which files to drag in together and exactly what to rename each folder to. Work through it in order.

What carries across

NameYes — and it is the only field onX lets you search.
DescriptionYes — arrives as the markup's Notes in onX.
IconYes, for waypoints. onX has 95; CalTopo has many more, so some map approximately.
ColorYes, snapped to onX's 10 waypoint colors (11 for lines).
FoldersYes — but only if you follow the import checklist.
Lines vs areasHandled automatically: lines and tracks go to GPX, areas to KML.

Good to know

  • Importing needs an onX Premium or Elite membership.
  • KML files (areas) can only be imported on the onX Web Map, not the phone app.
  • An onX account holds 1,500 markups; Cairn warns you if a map exceeds it.
  • Your map never leaves this computer — the conversion runs entirely in your browser.
