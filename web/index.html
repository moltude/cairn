CalTopo → onX Backcountry

CalTopo to onX, with icons and colors that still mean something.

Move your map without losing its icons, colors or folders.

onX can't read CalTopo's full GeoJSON export, and CalTopo's GPX and KML exports leave your icons, colors and folders behind, so your map lands in onX as a pile of identical blue pins. That hurts, because icon and color are how onX lets you filter. Cairn carries them across, lets you review and bulk-edit everything first, and hands you files ready to import.

How to use Cairn

1 · Export from CalTopo as GeoJSON

On your CalTopo map choose Export and pick GeoJSON. It keeps everything. CalTopo's KML works too: it keeps folders, icons and colors but not dashed lines. Drop that file here.

Cairn also opens GPX: a CalTopo GPX (names, notes and line colors, but no folders or icons, which you can add here), or the GPX and KML you export from onX to clean up an onX map. Drop the GPX and KML of one onX export together; they become one folder. Several files dropped at once become one folder each, named after the file.

2 · Review the icons

Cairn maps each CalTopo symbol to the closest onX icon, and shows each waypoint as the marker onX will draw. Hover any marker to see why it was chosen. Some waypoints fall back to onX's Default pin because CalTopo had no symbol and the name gave no clue — that is often perfectly fine (mile markers, numbered stops). Set an icon only where the meaning matters; choosing an icon — including deliberately choosing “Location” — marks it reviewed. Click a marker to change that one item's icon and color.

3 · Edit in bulk

Narrow the list with the search box, the type buttons, or the Folders and Icon lists on the left (tick Default pin to see only those). Then tick rows — Icon & color… applies to your selection. More holds Use note as name (when the real information is in the notes) and the export include/exclude controls.

Click a boxSelect one row.
Shift + clickSelect everything between it and the last row you clicked.
Ctrl / ⌘ + ASelect everything currently shown. Press again to deselect.
Header checkboxSelect every row in that folder.
EscClear the selection. While editing a name or note, Esc undoes that edit instead.
NotesClick a note to open it. Enter starts a new line; Ctrl / ⌘ + Enter applies.

Selection always follows what is on screen: filter first, then select all, and you only touch the rows you can see.

4 · Leave things out

Select rows and choose More → Exclude. Excluded rows stay visible, struck through, with an Include button. Useful for scratch lines and duplicated tracks. Nothing is ever deleted from your CalTopo file.

5 · Export and import

Cairn writes one set of files per folder and a checklist. This matters: onX creates one folder per import, and names it with a timestamp — never from the filename. So the checklist tells you which files to drag in together and exactly what to rename each folder to. Work through it in order.

What carries across

NameYes — and it is the only field onX lets you search.
NoteYes — arrives as the markup's Notes in onX.
IconYes, for waypoints. onX has 95; CalTopo has many more, so some map approximately.
ColorYes, snapped to onX's 10 waypoint colors (11 for lines).
FoldersYes — but only if you follow the import checklist.
Lines vs areasHandled automatically: lines and tracks go to GPX, areas to KML.

Good to know

  • Importing needs an onX Premium or Elite membership.
  • KML files (areas) can only be imported on the onX Web Map, not the phone app.
  • An onX account holds 3,000 markups; Cairn warns you if a map exceeds it.
  • Your map never leaves this computer — the conversion runs entirely in your browser.
  • The markers here are Cairn's own drawings, not onX's artwork; the icon name is exactly what onX will use.
