CalTopo → onX Backcountry

CalTopo to onX, with icons and colors that still mean something.

Move your map without losing its icons, colors or folders.

onX can't read CalTopo's full GeoJSON export, and CalTopo's GPX and KML exports drop your icons, colors and folders, so your map lands in onX as a pile of identical pins and lines. Cairn carries them across and lets you review and edit names, notes, icons and colors before you import. It reads CalTopo GeoJSON (best), KML and GPX.

How to use Cairn

1 · Export from CalTopo

In CalTopo choose Export, then GeoJSON. It keeps everything. KML works too, but loses dashed lines. Drop the file here.

CalTopo's GPX has no folders, icons or pin colors. Export GeoJSON (or KML) to keep them.

Cairn also opens GPX. A CalTopo GPX has names, notes and line colors; you can add icons here. To clean up an onX map, drop the GPX and KML of one onX export together: they become one folder. Drop several other files at once and each becomes a folder named after the file.

2 · Review the icons

Cairn picks the closest onX icon for each CalTopo symbol and draws each waypoint as onX will. Hover a marker to see why. A waypoint with no symbol and no clue in its name gets onX's Default pin, which is often fine (mile markers, numbered stops). Picking any icon, even Location (the default pin), marks it reviewed. Click a marker to change its icon and color, or a line's or area's color, style and weight.

Hover a name or note that's cut short to read all of it. A caution mark before a note means onX won't keep something as is: a note over onX's 512-byte import limit, an area fill onX resets, or an item with no coordinates. Hover the mark for details. The arrow in a Name header sorts that folder A–Z, then Z–A, then back to map order; each folder keeps its own. Sorting changes only the view.

3 · Edit in bulk

Narrow the list with the search box or the Type, Folders and Icon lists on the left (tick Default pin to see only those). Then tick rows. Icon & color… changes them all; it's Color… when only lines and areas are ticked, and with both, pins and lines each get their own color. Line style… sets the style and weight of lines and areas. More has Move to…, Use note as name, Exclude and Include.

Click a boxSelect one row.
Shift + clickSelect every row between it and the last one you clicked.
Ctrl / ⌘ + ASelect every row shown. Press again to deselect.
Header checkboxSelect every row shown in that folder.
EscClear the selection. While editing a name or note, undo that edit instead.
NotesClick a note to open it. Enter starts a new line; Ctrl / ⌘ + Enter saves.

Selection follows the screen: filter first, then select all, and you only touch the rows you can see.

4 · Folders

Each folder becomes one onX folder. To move rows, drag them onto a folder in the Folders list; tick several first to move them together. Drop them on + New folder to make a folder, then type its name. Clicking + New folder does the same with the ticked rows, or makes an empty folder when none are ticked (its × removes it). More → Move to… works from the keyboard. Click a folder's name above its rows to rename it; if the name is taken, Cairn offers to merge the two. A folder you empty goes away. Empty folders aren't exported. Folders are listed, and numbered at export, by name; Unorganized comes last.

5 · Leave things out

Tick rows and choose More → Exclude. Excluded rows stay in the list, struck through, with an Include button. Handy for scratch lines and duplicate tracks. Your CalTopo file is never changed.

6 · Export and import

onX creates one folder per import and names it with a date and time, never from the file name. So Cairn writes one set of files per folder. Download all gets every folder in one zip, with instructions.txt; a folder's Download gets just that folder. Import each folder's files together, tick Import map data to a new folder, then rename the new folder. instructions.txt lists each folder's name, its files and every item in them.

What carries across

NameYes. It's the only field onX searches.
NoteYes, as the markup's Notes in onX, up to 512 bytes.
IconYes, for waypoints. onX has 95 icons and CalTopo many more, so some are a close match, not an exact one.
ColorYes, snapped to onX's 10 waypoint colors (11 for lines).
Line styleYes, for lines and area outlines: solid or dashed, thin or thick. A dotted or extra-thin line from an onX file is kept.
FoldersYes. Import one folder at a time and rename each, as instructions.txt says.
Lines vs areasLines go out as GPX tracks, areas as onX areas with their outline color, style and weight. onX fills every imported area light blue, whatever the file says. Area holes aren't kept; instructions.txt marks those areas.

Good to know

  • Importing needs onX Premium or Elite.
  • Import on the onX Web Map on a computer. That's where the new-folder checkbox is.
  • An onX account holds 3,000 markups. Cairn warns you if a map has more.
  • Your map never leaves this computer. Everything runs in your browser.
  • The markers here are Cairn's drawings, not onX's artwork. The icon name is exactly what onX uses.
